Terminology

Relational Database:
it allows us to connect related information.

Database vs DBMS

Database:
- stores the data
- the data and the rules


DBMS:
- Manages and provides access to the database
- Software that allows us to interact with the data



Examples of DBMS:
- PostgreSQL - opensource, powerful
- SQLite - lightweight, embedded
- Oracle - Enterprise , large scale
- SQL Server - Microsoft specific
